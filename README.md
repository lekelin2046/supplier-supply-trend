# 供应商 2026 上半年供货额趋势查询

纯前端、离线可用的供货额趋势查询页面。数据源为「供应商 2026 年上半年供货额」明细，已透视为「客户 × 月份」，并支持以下能力：

- **单家模糊查询**：支持非连续子序列匹配（如输入「保定诚业」可命中「保定市诚业」）。命中 ≤ 8 家自动展开趋势图，超过则点击具体客户行展开。
- **批量查询**：粘贴多个企业全称（每行一个），结果以表格呈现，可一键导出 Excel（.xlsx）。
- **内嵌 SVG 趋势图**：1–6 月供货额走势，无外部依赖。
- **数据全部内嵌**：页面自包含，无 CDN、可离线打开。

## 访问地址

GitHub Pages：`https://lekelin2046.github.io/supplier-supply-trend/`

## 数据口径

- 汇总为**去重后**结果（已剔除客户+月份+金额完全相同的重复行）。
- 月均额取 **4–6 月**均值；若任一月缺数据则留空。
- 数据覆盖 2026 年 1–6 月，约 3500+ 家客户。
